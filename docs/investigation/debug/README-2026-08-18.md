# Debug knobs built 2026-08-18 for the PC MASTER OUT investigation

All prefix-local or system-file, all reverted. Sources kept so the next session
can rebuild them without rediscovering the wiring.

| knob | where | what it does |
|---|---|---|
| `RBW-QUIET` | `dlls/mmdevapi/client.c` | silences the three hot TRACEs (`GetCurrentPadding`, `GetBuffer`, `ReleaseBuffer`). Drops `WINEDEBUG=+mmdevapi` from 200,000 lines/s to 2 KB/s and makes the channel usable. **The single most useful thing built today.** |
| `RBW_EXCL_PERIODS` / `RBW_SHARED_PERIODS` | `adjust_timing` | override Wine's buffer inflation (defaults 4 and 3 reproduce shipping). |
| `RBW_FORCE_SHARED=1` | `stream_init` | serve an EXCLUSIVE request as SHARED. Builds the "is it exclusivity or just two devices?" arm that the application's UI cannot. |
| `RBW_SESSION_NOTIFY=fail\|impl` | `dlls/mmdevapi/session.c` + `client_Start/Stop` | make `RegisterAudioSessionNotification` fail honestly, or actually deliver `OnStateChanged`. Wine ships a lying stub that returns S_OK and never calls back. |
| `RBW_MMCSS=1` | `dlls/avrt/main.c` | implement `AvSetMmThreadCharacteristics` as `THREAD_PRIORITY_TIME_CRITICAL`. |
| `RBW_EVENT_GATE=any\|half` | `dlls/winealsa.drv/alsa.c` | relax the condition under which the stream event is signalled. |
| `RBW-JITTER` | same | per-stream interval between event signals: count, mean, worst, once a second. |

`winealsa-gate-jitter.c.txt` is the alsa.c carrying the last two.

**Results are in `docs/investigation/THEMES/T03-audio-device.md` phases 26 and 27.** Every one of
these except `RBW-QUIET` and `RBW-JITTER` left the engine at 0.05x.
